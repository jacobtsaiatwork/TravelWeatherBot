FortiClient 訂購指南 (Ordering Guide)

繁體中文版 ｜ 文件代號: FC-OG-R27-20260429
概要說明：FortiClient 提供彈性的訂購結構以滿足各種規模組織的資安防護需求，全面採用依設備計費授權模式（Device-based Licensing）。

1. 關鍵重點與訂購特性 (Key Aspects)

  • 部署模式選項 (Deployment Options)：客戶可依架構自由選擇雲端託管 (Cloud) 或地端內部部署 (On-premise)。
  • 解決方案專用料號 (Solution SKUs)：針對不同安全層次提供專屬 SKU 套裝，包括 VPN/ZTNA、EPP/ATP 以及由原廠專家交付的 Managed FortiClient 代管服務。
  • 附加增值服務 (Additional Services)：提供端點數位鑑識分析（Endpoint Forensics Analysis）與 FortiCare 最佳實踐顧問諮詢（BPS Consultation）。
  • FortiToken 授權權益：FortiClient 授權不包含 FortiToken MFA 權益，如需雙因子驗證必須另行加購。
  • 設備授權包級距 (Device-Based Licensing)：提供 25、500、2000 與 10,000 台設備包 彈性採購。
  • 合約生命週期管理 (Order Lifecycle Management)：建議使用原廠 Co-term（到期日對齊工具）管理後續增購、續約與版本升級，統一多張合約之到期日，簡化企業授權維運。
  • 跨架構升級限制 (Upgrade Limitations)：不支援直接由地端（On-premise）SKU 升級換成雲端（Cloud）SKU。若欲切換架構，必須採購全新 SKU 並對齊新的 EMS 實例。

8. 常見問題集 (Frequently Asked Questions)

Q1：什麼是 BPS？為什麼新專案都強烈建議納入？
答：BPS 提供與 Fortinet 原廠產品專家預約諮詢的管道，涵蓋解決方案部署指引、穩定產品升級路徑建議、授權升級指南，以及最低資料遺失、終端使用者無感的 EMS 遷移技術支援。強烈建議在每一筆新客戶專案中加入 BPS。
Q2：最簡單的下單方式是什麼？
答：提供 1 到 5 年期的設備數量包。增購、續約與升級請參考第 3 節的 Co-term 訂單生命週期操作實例。
Q3：FortiClient 是依使用者（Per-user）還是依設備（Per-device）計費？
答：無論是地端內部部署的 FortiClient EMS 還是雲端 FortiClient Cloud，一律依設備 / 端點 (Per-device / Endpoint) 計費授權。（僅 Standalone DIY 版依使用者計費）。
Q4：原本第一、二頁的 SASE 選項去哪了？
答：所有 SASE 選項均完整保留。Fortinet 已將 SASE 相關內容整併至獨立的《FortiSASE 訂購指南》，並支援將 FortiClient 授權升級為 FortiSASE。
Q5：如何從現有 FortiClient 授權升級到更高階授權？
答：可透過原廠 Co-term（到期日對齊工具）計算差額升級。請特別注意：不支援地端 EMS 與雲端 Cloud EMS 之間的直接升級切換。
Q6：EMS 管理伺服器有哪些部署選項？
答：可安裝於 Linux 伺服器（7.4 版）或 Windows 伺服器（7.2 及更早版本），可部署於本地機房（On-premise）或公有雲。亦可直接採用原廠託管的 FortiClient Cloud SaaS 服務。
Q7：什麼是 FortiClient Cloud？
答：FortiClient Cloud 是由 Fortinet 原廠代管維護的 EMS 實例，企業無須自行建置與維護地端伺服器硬體與作業系統。
Q8：FortiClient Cloud 最多可管理多少台端點？
答：單一 FortiClient Cloud 實例最高可集中管理高達 250,000 台端點。
Q9：什麼是 ZTNA？
答：ZTNA 指的是 FortiOS 與 FortiClient 內建以代理為基礎（Proxy-based）的零信任網路存取功能，包含端點設備安全狀態檢查（Posture Checks）、數位憑證生命週期管理，以及安全加密連線存取 FortiGate 後方的應用系統。
Q10：我之前購買的是 EMS01 / EMS03 舊料號，能否直接升級至新的 EMS04 / EMS05 料號？
答：由於產品功能架構調整，無法直接升級。客戶應於合約到期續約時採購全新 SKU 料號。若以往是使用舊料號的地端部署，建議順勢直接轉換遷移至雲端 FortiClient Cloud 方案。
Q11：使用 FortiClient Cloud 是否強制需要 FortiCloud Premium 高級訂閱？
答：不需要。FortiClient Cloud 不強制要求綁定 FortiCloud Premium 訂閱。
Q12：同一台 EMS 能否同時混合使用不同的授權類型（如 VPN/ZTNA 與 EPP/ATP 混合）？
答：技術上可以支援。
Q13：如果 VPN/ZTNA 與 EPP/ATP 的授權到期日不同，同一台 EMS 能否支援混合？
答：強烈建議客戶使用單一授權類型，避免在同一台 EMS 上混用不同類型與到期日的授權，以簡化管理複雜度。
Q14：什麼是 FortiClient 數位鑑識分析服務 (Forensics Service)？
答：此服務提供遠端端點數位鑑識分析，協助企業應對網路資安事件並快速復原。FortiGuard Labs 原廠鑑識分析專家會遠端協助數位證據的收集、鑑定與呈現，並產出最終鑑識報告。支援 FortiClient Cloud 以及 7.2.2 版以上之地端 EMS。
Q15：什麼是 FortiEndpoint？
答：FortiEndpoint 是以 FortiClient 為核心的統一端點安全平台，提供單一代理程式 (Agent)、單一授權與單一管理後台，全面融合了安全連線（VPN / ZTNA）與 EPP、EDR、XDR 等威脅偵測回應能力。詳細資訊請參閱《FortiEndpoint 訂購指南》。

9. 導入與上線服務 (Onboarding)

  • 自主手動導入 (Manual / DIY)：原廠提供完整的官方文件、教學影片、開源工具庫與各類技術資源。
  • 最佳實踐顧問諮詢 (FortiCare BPS)：採用年度訂閱制的 FortiCare BPS，由原廠專家全程提供建置部屬、架構整合與版本升級遷移的顧問指引，深度整合於 FortiCare 支援體系。
  • 原廠端點專家代管 (Managed FortiClient)：初始環境設定、安全設定與設備上線皆直接由 Fortinet 原廠專家開箱交付。
  • 專案專業建置服務 (Professional Service, PS)：對於要求嚴格合約服務等級協定（SLA）的大型或客製化建置專案，PS 專業服務是絕佳的交付選項。
